How this was built

This site was assisted by Claude Opus 5.5, an AI model from Anthropic. Shane Wood set the scope, reviewed drafts of the site and asked for changes. Claude searched the web, read program pages, drafted the 106 entries and wrote the code. Users should check every entry to confirm accurate information before drafting materials, applying, or paying.

Where the information comes from

PhD entries start from Rhetoric and Composition Doctoral Program Profiles, compiled by the Consortium of Doctoral Programs in Rhetoric & Composition and last updated November 2025. That is the source for program descriptions, strengths, admit rates, stipends and funding. Programs supplied those answers, so they vary in detail and wording.

Claude then read each PhD program’s admissions pages where it could. Where a profile and a program’s current page disagree, the program’s page wins. Twenty PhD entries come from Rhet Map’s list of doctoral programs in rhetoric and composition, added only where a program’s own pages named rhetoric or composition. These and the MA entries are built from each program’s own pages. Where an MA sits at a school with a PhD, its strengths come from that school’s doctoral profile.

Fees, dates and status

Fees marked “Stated” appear on a university or program page. Fees marked “Confirm” came from third-party listings or related pages. Dates without a printed year are shown for the next cycle. Some pages blocked automated reading, so a few entries have gaps. Admissions status can change, so confirm that a program is taking applications before you start.

Faculty links

Each “All faculty” link goes to a department or program page found November 5, 2026. Some departments list everyone together, so rhetoric and composition faculty may be mixed in with others. A few links go to a contact or home page that leads to the list.

Research

The research filter uses each program’s own “Program strengths” answer from the Consortium profiles, gathered under shared labels. Those labels are ours, not the Consortium’s. Many programs listed things like mentoring or funding there, so they won’t appear under a research topic. To find a topic across mission statements, use the search box.

Reading the entries

Each entry links to its sources where we have them. A blank means we don’t have the information, not that the program lacks it.
